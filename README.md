# MRF - Previsão da Inflação Brasileira

Aplicação do algoritmo Macroeconomic Random Forest (MRF) 
na previsão do IPCA — SINAPE 2026.

## Autores
- Leonardo Carvalho Ribeiro da Silva (UFRGS)
- Hudson da Silva Torrent (UFRGS)

## Estrutura
- `scripts/` — códigos em R
- `data/` — dados extraídos do Ipeadata
- `output/` — gráficos e tabelas de resultados

## Modelos
- Benchmark: ARIMA
- Principal: Macroeconomic Random Forest (MRF)
